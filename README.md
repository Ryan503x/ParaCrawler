# ParaCrawler

أداة زحف واستطلاع لتطبيقات الويب مكتوبة بلغة بايثون، تساعد مختبري الاختراق والباحثين الأمنيين على اكتشاف الروابط والمعاملات وحقول الإدخال، وجمع مؤشرات قد تكون مفيدة أثناء مرحلة الاستطلاع وتحليل سطح الهجوم.

تقوم الأداة بالزحف داخل النطاق المستهدف، وتحليل صفحات الويب، ثم عرض النتائج في الطرفية أو حفظها بصيغتي CSV وJSON.

> [!IMPORTANT]
> استخدم هذه الأداة فقط على الأنظمة التي تملكها أو لديك تصريح صريح لاختبارها. أنت مسؤول عن الالتزام بالقوانين ونطاق الاختبار المتفق عليه.

## المزايا

- اكتشاف الروابط ونقاط النهاية داخل النطاق المستهدف.
- استخراج معاملات الاستعلام من عناوين URL.
- استخراج حقول النماذج مثل `input` و`select` و`textarea`.
- التمييز بين حقول HTML الموجودة داخل النماذج والحقول التي يُحتمل أن تتحكم بها JavaScript خارج النماذج.
- اكتشاف الحقول المخفية والأزرار والعناصر النائبة.
- تحليل تعليقات HTML وJavaScript والبحث عن كلمات أو قيم قد تكون حساسة.
- اكتشاف أرقام الإصدارات وعناوين IPv4 الظاهرة في المحتوى الذي تم تحليله.
- اكتشاف بعض المسارات المرتبطة بتطبيقات SvelteKit.
- دعم اختياري للزحف إلى النطاقات الفرعية التابعة للنطاق الجذري نفسه.
- تنفيذ الطلبات بالتوازي مع جلسة HTTP مستقلة لكل خيط وإمكانية تحديد عدد الخيوط.
- معالجة الصفحات فور اكتمالها بدل انتظار الطلبات الأبطأ في الدفعة نفسها.
- توحيد عناوين URL لتقليل تكرار الزحف الناتج عن اختلاف حالة الأحرف والمنافذ الافتراضية والشظايا.
- تطبيق حد صارم لعدد العناوين عند استخدام `--max-urls`.
- التحكم في التأخير والمهلة والحجم الأقصى للاستجابة.
- عرض دليل ألوان النتائج عند بدء التشغيل.
- إعادة محاولة بعض الطلبات التي فشلت أو انتهت مهلتها.
- جمع روابط بعض الملفات والموارد غير التابعة لصفحات HTML.
- حفظ النتائج بصيغة CSV المتوافقة مع Excel أو بصيغة JSON.
- وضع تصحيح لعرض تفاصيل إضافية أثناء الزحف.

## المتطلبات

- بايثون 3.9 أو أحدث.
- اتصال بالشبكة يسمح بالوصول إلى الهدف.
- المكتبات التالية:
  - `requests`
  - `beautifulsoup4`
  - `colorama`
  - `scrapy`
  - `dnspython` لدعم استعلامات DNS الاختيارية

## التثبيت

### استنساخ المستودع

```bash
git clone https://github.com/Ryan503x/ParaCrawler.git
cd ParaCrawler
```

### إنشاء بيئة افتراضية

على لينكس أو macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

على ويندوز:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### تثبيت الاعتماديات

```bash
python -m pip install -r requirements.txt
```

## الاستخدام السريع

```bash
python paracrawler.py -u https://example.com
```

حفظ النتائج بصيغة CSV:

```bash
python paracrawler.py -u https://example.com -o results.csv
```

حفظ النتائج بصيغتي CSV وJSON معًا:

```bash
python paracrawler.py -u https://example.com -o results.csv -j results.json
```

## خيارات سطر الأوامر

| الخيار | الصيغة الطويلة | الوصف | القيمة الافتراضية |
|---|---|---|---|
| `-u` | `--url` | عنوان الهدف الأساسي، وهو خيار مطلوب | لا توجد |
| `-o` | `--output` | حفظ النتائج في ملف CSV | لا يتم إنشاء ملف |
| `-j` | `--json-output` | حفظ النتائج في ملف JSON | لا يتم إنشاء ملف |
| `-m` | `--max-urls` | تحديد أقصى عدد من العناوين التي يمكن زحفها | دون حد صريح |
| `-t` | `--threads` | تحديد عدد خيوط الزحف المتزامنة | `10` |
| — | `--delay` | التأخير بالثواني قبل كل طلب | `0.1` |
| — | `--timeout` | مهلة قراءة الاستجابة بالثواني | `10` |
| — | `--retries` | عدد محاولات كل عنوان عند فشل الشبكة أو انتهاء المهلة | `1` |
| — | `--no-https-fallback` | تعطيل تجربة HTTPS تلقائيًا عند فشل HTTP | معطل |
| — | `--max-size` | أقصى حجم لمحتوى HTML بالميبيبايت | `1` |
| — | `--subdomains` | السماح بالزحف إلى النطاقات الفرعية التابعة للنطاق نفسه | معطل |
| — | `--debug` | عرض معلومات تفصيلية تساعد في التشخيص | معطل |

لعرض رسالة المساعدة:

```bash
python paracrawler.py --help
```

## أمثلة عملية

### تحديد عدد الصفحات

```bash
python paracrawler.py -u https://example.com -m 100
```

### تغيير عدد الخيوط

```bash
python paracrawler.py -u https://example.com -t 20
```

ابدأ بعدد منخفض من الخيوط، ثم ارفعه فقط عندما يسمح نطاق الاختبار وقدرة الخادم بذلك.

### تضمين النطاقات الفرعية

```bash
python paracrawler.py -u https://example.com --subdomains
```

### تشغيل وضع التصحيح

```bash
python paracrawler.py -u https://example.com --debug
```

### فحص محدود مع حفظ النتائج

```bash
python paracrawler.py \
  -u https://example.com \
  -m 200 \
  -t 10 \
  --subdomains \
  -o paracrawler-results.csv \
  -j paracrawler-results.json
```

وفي موجه أوامر ويندوز يمكن كتابة الأمر في سطر واحد:

```powershell
python paracrawler.py -u https://example.com -m 200 -t 10 --subdomains -o paracrawler-results.csv -j paracrawler-results.json
```

## البيانات التي تجمعها الأداة

لكل نقطة نهاية، قد تتضمن النتائج ما يلي:

- عنوان URL.
- رمز حالة HTTP عند توفره.
- معاملات الاستعلام.
- حقول HTML داخل النماذج.
- الحقول الموجودة خارج النماذج والتي قد تعتمد على JavaScript.
- الأزرار والحقول المخفية والعناصر النائبة.
- التعليقات التي تحتوي على مؤشرات حساسة محتملة.
- أرقام الإصدارات.
- عناوين IPv4.
- الملفات المكتشفة.
- العناوين التي أعادت حالة 404.
- العناوين التي انتهت مهلة طلبها.

## ملفات النتائج

### ملف CSV

يحتوي ملف CSV على أعمدة منظمة للعنوان، ومعاملات الاستعلام، وحقول HTML، وحقول JavaScript، والأزرار، والحقول المخفية، والنتائج الحساسة المحتملة، والإصدارات، وعناوين IP. وقد تُضاف في نهايته أقسام منفصلة للملفات المكتشفة والعناوين الفاشلة.

مثال:

```bash
python paracrawler.py -u https://example.com -o results.csv
```

### ملف JSON

يوفر ملف JSON بنية أكثر تفصيلًا، ويشمل ملخص عملية الزحف وقائمة نقاط النهاية والملفات المكتشفة والعناوين الفاشلة والمنتهية المهلة.

مثال:

```bash
python paracrawler.py -u https://example.com -j results.json
```

## فهم النتائج

العثور على كلمة مثل `password` أو `token` أو عنوان IP أو رقم إصدار لا يعني تلقائيًا وجود ثغرة أمنية. تعامل مع النتائج على أنها مؤشرات أولية تحتاج إلى تحقق يدوي وسياق إضافي.

يُنصح بمراجعة ما يلي بعد انتهاء الزحف:

1. نقاط النهاية التي تحتوي على معاملات استعلام قابلة للاختبار.
2. الحقول المخفية وحقول الإدخال غير المعتادة.
3. التعليقات التي قد تكشف أسرارًا أو معلومات داخلية.
4. أرقام الإصدارات التي قد ترتبط بمكونات قديمة.
5. المسارات والملفات غير المتوقعة.
6. النطاقات الفرعية التي ظهرت أثناء التحليل.

## ملاحظات وحدود حالية

- تعتمد الأداة أساسًا على تحليل المحتوى الذي يعيده الخادم، ولا تشغّل JavaScript داخل متصفح حقيقي.
- قد تفوتها المسارات التي لا تظهر إلا بعد تفاعل المستخدم أو بعد تنفيذ JavaScript ديناميكيًا.
- اكتشاف المعلومات الحساسة مبني على أنماط وكلمات مفتاحية، لذلك قد ينتج عنه إنذارات كاذبة.
- اكتشاف عناوين IPv4 وأرقام الإصدارات لا يثبت وجود مشكلة أمنية.
- يعتمد تحديد النطاق الجذري على قائمة اللواحق العامة المضمّنة في `tldextract`، من دون تنزيل بيانات أثناء التشغيل.
- تتحقق الأداة من شهادات TLS بصورة غير صارمة حاليًا، لذلك لا ينبغي اعتبار نجاح الاتصال دليلًا على سلامة الشهادة.
- قد تؤثر أنظمة الحماية، وحدود المعدل، وملف `robots.txt`، وتأخير الشبكة في النتائج.
- الزحف بعدد مرتفع من الخيوط قد يسبب ضغطًا على الخادم؛ استخدم إعدادات مناسبة ومصرحًا بها.

## الاستخدام المسؤول

قبل تشغيل الأداة:

1. احصل على تصريح مكتوب عندما لا يكون النظام ملكك.
2. حدد النطاقات والعناوين المسموح اختبارها بدقة.
3. اتفق على معدل الطلبات والفترة الزمنية للاختبار.
4. تجنب جمع أو تخزين بيانات شخصية لا تحتاج إليها.
5. احمِ ملفات النتائج لأنها قد تحتوي على معلومات حساسة.
6. أوقف الفحص فورًا إذا تسبب في عدم استقرار الخدمة.

## أفكار للتطوير

- دعم JavaScript عبر متصفح آلي اختياري.
- إضافة إعدادات مخصصة للمهلة والتأخير وعدد المحاولات.
- دعم رؤوس HTTP وملفات تعريف الارتباط والمصادقة المخصصة.
- احترام `robots.txt` عبر خيار صريح.
- إضافة مرشحات لتضمين المسارات أو استبعادها.
- إضافة حد لعمق الزحف.
- إضافة سجل منظم للأخطاء والأحداث.
